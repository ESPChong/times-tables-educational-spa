For teachers — the learning idea behind this

Retrieval practice with immediate corrective feedback. Roediger & Karpicke (2006), “Test-Enhanced Learning: Taking Memory Tests Improves Long-Term Retention”, Psychological Science 17(3).

Mapping: every fact must be produced — spoken or typed — before it is shown again. A miss gets immediate correction, a spoken “say it back” rehearsal, and a delayed re-test a few items later (not an instant second guess, which would only be recognition).

What would count as the idea failing: showing answers before the learner tries, saving feedback until the end of the round, or re-testing only immediately — any of those would remove the effortful retrieval that drives the effect, and this would be a slide deck.
